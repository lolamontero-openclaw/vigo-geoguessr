VigoGuessr

GeoGuessr ambientado en Vigo: mira la foto y sitúala en el mapa.

Modo: solo

Jugar solo

Elige número de rondas y dificultad. Luego pulsa “Jugar solo”.

Jugar con otro dispositivo

Uno crea sala y comparte el código. El otro abre el mismo HTML en otro móvil/PC, introduce el código y pulsa “Unirse”.

Sin conexión online.

Cómo compartirlo

Puedes enviar este archivo HTML por WhatsApp, correo, Drive, etc. Cada persona lo abre en su navegador. Para el modo online, ambos necesitan internet.

Si al abrirlo como archivo local el modo online falla en algún móvil, sube el HTML a un hosting estático gratuito como GitHub Pages, Netlify o Cloudflare Pages.
